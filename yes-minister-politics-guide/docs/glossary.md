# Glossary — What They Actually Mean

The series runs on euphemism: the surface meaning is polite, the real meaning is the move.
This is a decoder for the recurring phrases.

| Phrase | What it actually means |
| --- | --- |
| **"Yes, Minister."** | "No." (Polite agreement that nothing will actually change.) |
| **"That's a very courageous decision, Minister."** | "That decision will end your career — voters will hate it." |
| **"A bold decision."** | A milder version of *courageous*: risky, but you might survive it. |
| **"With respect…"** | "You are wrong." |
| **"With the greatest possible respect…"** | "You are completely, dangerously wrong." |
| **"In due course." / "In the fullness of time."** | "Never — or so late it won't matter." |
| **"The time is not yet right."** | "I will make sure the time is never right." |
| **"Under consideration."** | "We've lost the file." |
| **"Under active consideration."** | "We're looking for the file." |
| **"We must proceed with caution."** | "We must not proceed." |
| **"I think we need to set up a committee."** | "I'm going to bury this." |
| **"This needs further study / a review."** | "I'm going to delay this until it dies." |
| **"We should consult more widely."** | "More delay, dressed as diligence." |
| **"It's a very complex/sensitive area."** | "I don't want you touching it." |
| **"That's not a matter for this department."** | "Not my problem; pass it on and lose it." |
| **"Mistakes were made."** | "Something went wrong and no one will be named." |
| **"I'm glad you asked me that."** | "I am about to not answer that." |
| **"Let me be absolutely clear."** | "I am about to be deliberately unclear." |
| **"Broadly speaking…" / "By and large…"** | "What follows is too vague to be held against me." |
| **"Some might say…" / "It could be argued…"** | "This is my view, but I won't own it." |
| **"A leak."** | An unauthorised disclosure (by someone I dislike). |
| **"Keeping the press informed." / "A briefing."** | The same disclosure, but done by my side. |
| **"Notable progress has been made."** | "Nothing has happened, but we'll say it nicely." |
| **"We are where we are."** | "Stop asking how we got into this mess." |
| **"Going forward."** | Filler that signals motion while committing to nothing. |
| **"A free and frank exchange of views."** | A serious argument. |
| **"A full and frank exchange of views."** | A blazing row in which nothing was agreed. |
| **"Taken at official level."** | "Decided by civil servants, so the minister can disown it." |
| **"Noted."** | "Heard, and intend to do nothing." |
| **"The public interest."** | Often: whatever protects the department or avoids embarrassment. |
| **"Open government."** | A contradiction in terms — you can be open *or* you can govern. |

> Rule of thumb: the more courteous and elaborate the phrasing, the more it is hiding. When you
> hear "with the greatest possible respect," reach for the playbook.
